# Atividade React Native — Listas e Formulários

Projeto individual desenvolvido por **Gustavo Araújo do Carmo**, RA **22304113**, para o curso de Análise e Desenvolvimento de Sistemas — Taguatinga Noturno.

## Conteúdo da entrega

### Parte 1
Lista temática sobre organização e produtividade com cinco informações e seis imagens no total.

### Parte 2
Interação por toque: cada item abre e fecha uma descrição detalhada. Há cinco descrições com pelo menos 30 palavras cada e 174 palavras no total.

### Parte 3
Segunda tela com:

- título;
- quatro inputs de texto;
- dois Pickers;
- dois Sliders;
- dois Switches;
- dois botões com interação.

## Tecnologias

- React Native
- Expo
- JavaScript
- App.js

## Como executar

```bash
npm install
npm start
```

Use o aplicativo Expo Go para ler o QR Code ou pressione `a`, `i` ou `w` no terminal.

## Validar requisitos

```bash
npm test
```

O teste verifica automaticamente a quantidade de telas, imagens, textos e controles solicitados.
